📋 RESUMO DO PROJETO
═══════════════════════════════════════════════════════════════════════════════

Backend profissional e resiliente para a Rádio Nova Dimensão FM, desenvolvido
em Node.js com Express. Integração completa com a plataforma BRLOGIC para
streaming de áudio ao vivo e metadados em tempo real.

🎯 CARACTERÍSTICAS PRINCIPAIS
═══════════════════════════════════════════════════════════════════════════════

✓ Proxy de Áudio Inteligente
  - Streaming com retry automático (até 3 tentativas)
  - Backoff exponencial para evitar sobrecarga
  - Suporte a range requests para seeking

✓ API de Metadados
  - Busca em tempo real de música/artista/capa
  - Cache inteligente com TTL configurável (30s padrão)
  - Fallback automático em caso de falha

✓ Health Check
  - Monitoramento contínuo da saúde do serviço
  - Endpoint /api/health para status em tempo real
  - Detecção de degradação de serviço

✓ Tratamento de Falhas
  - Cache com fallback automático
  - Dados padrão como último recurso
  - Nunca retorna erro completo ao usuário

✓ CORS Habilitado
  - Integração perfeita com frontends modernos
  - Configuração flexível de origens permitidas

✓ Logging Completo
  - Rastreamento detalhado de todas as operações
  - Identificação de problemas facilitada

✓ Graceful Shutdown
  - Encerramento elegante do servidor
  - Tratamento de sinais SIGTERM/SIGINT

🔌 ENDPOINTS DA API
═══════════════════════════════════════════════════════════════════════════════

GET /api/metadata
  └─ Retorna metadados atuais (música, artista, capa, ouvintes)
  └─ Cache: 30 segundos
  └─ Fallback: Dados padrão se API falhar

GET /api/stream
  └─ Proxy do stream de áudio da BRLOGIC
  └─ Retry: Até 3 tentativas com backoff exponencial
  └─ Suporta range requests

GET /api/health
  └─ Verifica saúde do serviço
  └─ Status: healthy/degraded/unhealthy
  └─ Detalhes de cada serviço

GET /api/info
  └─ Informações sobre o backend
  └─ Versão, ambiente, uptime

GET /api/cache/stats
  └─ Estatísticas do cache (desenvolvimento)

POST /api/cache/clear
  └─ Limpa o cache manualmente (desenvolvimento)

🚀 QUICK START
═══════════════════════════════════════════════════════════════════════════════

1. Instalar dependências:
   $ npm install

2. Configurar variáveis de ambiente:
   $ nano .env

3. Executar em desenvolvimento:
   $ npm run dev

4. Executar em produção:
   $ npm start

5. Testar API:
   $ node test-api.js

6. Acessar exemplo:
   $ Abrir example.html no navegador

🛠️  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Erro: "ECONNREFUSED"
  → Verificar se BRLOGIC está online
  → Verificar URLs em .env

Erro: "CORS error"
  → Verificar CORS_ORIGIN em .env
  → Deve incluir domínio do frontend

Erro: "Timeout"
  → Aumentar timeout em config.js
  → Verificar velocidade de conexão

Erro: "Stream não funciona"
  → Verificar /api/health
  → Verificar logs: npm start
